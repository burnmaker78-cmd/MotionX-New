MotionX

A creative video editor for iPhone and the web.

MotionX is an evolving video-editing project based on Open-Motion, with the goal of building a mobile-friendly editing experience inspired by professional editors.

✨ Features

* 🎬 Video-editing workspace
* 📱 Mobile-friendly interface
* 🎨 Custom MotionX branding
* ✨ Planned visual effects, including Glow, Tiles, Wave Warp, and Oscillate
* 🎞️ Timeline and clip-editing improvements
* 📦 Planned iOS app packaging (.ipa)

🚀 Project Goals

Our goal is to customize Open-Motion into MotionX by developing:

* A dedicated MotionX interface
* A collection of adjustable visual effects
* Improved mobile editing controls
* An iOS app experience
* Additional creative tools and features

📲 iOS App

MotionX is intended to be packaged as an iOS application. An installable IPA requires an appropriate iOS build process and signing configuration.

Status: In development.

🛠️ Development

MotionX is based on the Open-Motion project. Refer to the repository’s existing setup instructions to install dependencies and run the project.
